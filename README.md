# Lịch Việt

App Android: lịch dương – âm (Việt Nam), đồng hồ, thời tiết theo vị trí + 4 widget màn hình chính.

- Âm lịch: thuật toán thiên văn (Hồ Ngọc Đức), múi giờ GMT+7
- Thời tiết: Open-Meteo, mặc định mô hình ECMWF IFS 9 km (đổi trong Cài đặt)
- Widget: Đồng hồ & Lịch (4×2), Thanh gọn (4×1), Thời tiết (4×3), Lịch ngày (2×2) – tùy chỉnh nền trong suốt, màu, kiểu giờ/ngày

## Build
GitHub Actions tự build mỗi lần push → tab **Actions** → bản build mới nhất → tải `LichViet-apk`.
